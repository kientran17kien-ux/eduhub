# EduHub - Event Registration System

## 1. Introduction

EduHub is a C# Console application developed to manage students, events, and event registrations.

The project demonstrates Object-Oriented Programming (OOP) concepts in C#.

## 2. Features

- Manage student information.
- Manage event information.
- Register students for events.
- Prevent duplicate registrations.
- Display the total number of students, events, and registrations.
- Display the list of students registered for each event.

## 5. How to Run

Open a terminal in the project directory and run:

```bash
dotnet run
```

## 6. Testing

The application can be tested by checking:

- The total number of students.
- The total number of events.
- The total number of registrations.
- The list of registered students for each event.
- The rejection of duplicate registrations.
